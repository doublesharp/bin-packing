# v0.4.0

An additive release for Rust, native Node.js, and WebAssembly.

- Add opt-in saw planning with workpiece-relative fence and stop settings, kerf-aware cuts, physical cut dependencies, and effort-weighted scheduling.
- Expose the planner through native Node.js and combined and 2D WASM packages, with TypeScript declarations and executable examples.
- Preserve original demand dimensions and rotation permissions during assignment search; bound demand expansion and exhaustive rotation search.
- Reduce repeated geometry calculations, 3D contact scoring work, and saw-planner beam allocations.
- Fix JavaScript numeric result handling and large solve-to-cut roundtrips, and correct WASM initialization types and target builds.
- Expand physical replay, asymmetric regression, feature-combination, packaged-consumer, browser, and generated-case checks. Correct tests that imposed unsupported solver guarantees.
- Validate native platform dependencies, package contents, and compiled versions before publication.

## Packages

All packages use version `0.4.0`:

- crates.io: `bin-packing`
- npm: `@0xdoublesharp/bin-packing`
- npm: `@0xdoublesharp/bin-packing-wasm`, including all 12 combined and dimension-specific export paths
- npm native packages: `@0xdoublesharp/bin-packing-{linux-x64-gnu,linux-arm64-gnu,darwin-x64,darwin-arm64,win32-x64-msvc,win32-arm64-msvc}`

The binding implementation crates remain `publish = false`; they are distributed through npm. Existing packing and cutting APIs remain available. JavaScript numeric output follows the existing `number` contract, including its precision limits for large integers.

See [saw planning](../two-d/saw-planner.md), [measured results](../two-d/saw-planner-results.md), and [workspace verification](../workspace-verification.md).
