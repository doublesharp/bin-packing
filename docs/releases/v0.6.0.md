# v0.6.0

Add native irregular nesting, physical cutting/loading models and explicit
packing objectives to Rust, Node.js and WebAssembly.

- Add [irregular nesting](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/irregular.md) for concave polygons, holes, circles,
  arcs, rigid components, irregular stock/defects, rotations, reflection and
  spacing. Reject polygon holes that touch their exterior, including at a point.
- Add [staged 2D cutting](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/two-d/staged.md) with authoritative physical cut
  trees, stage/cut modes, machine limits, kerf, trims, defects and cutting groups.
- Add [3D stack loading](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/three-d/loading.md) with upright nested columns,
  stack/weight/density limits, payload, axle reactions and unloading groups.
- Add [explicit objectives](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/objectives.md) for material cost, profit/knapsack,
  feasibility and open dimensions, with mandatory quantities and source-indexed
  results. Node/WASM expose `solve1dOptimized`, `solve2dOptimized`,
  `solve3dOptimized`, `solve2dStagedOptimized` and `solve3dLoadingOptimized`.
- Add [1D minimum cost](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/one-d/min-cost.md), [constrained 2D](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/two-d/constrained.md)
  and [constrained 3D](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/three-d/constrained.md), plus [adaptive 2D](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/two-d/adaptive.md)
  selection and conservative [sheet-count bounds](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/two-d/bounds.md).
- Improve constrained 2D repair: the dense 15-part regression now uses two sheets
  within the default 4,000-state budget, including a ten-times-scaled copy.
- Refresh Rust and JavaScript examples, algorithm/proof descriptions and the
  complete physical/objective API guides. Add generated versions, features,
  exports and defaults, local-link checks and executable documentation examples
  to CI before publication. See [documentation maintenance](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/documentation.md)
  and the [release runbook](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/releasing.md).
- Add independent geometry, accounting, physical-rule and small-instance oracle
  tests, reproducible coverage tooling and contributor/security documentation.

## Compatibility and limits

Existing packing and saw-planning entry points remain available. This pre-1.0
minor release adds public modules, types and structured `InvalidConstraint` and
`InvalidSolution` errors. `BinPackingError` remains non-exhaustive.

The `irregular` feature is enabled by default in Rust and both bindings and adds
the safe Rust `geo` dependency. Rust consumers can select dimensions with
`default-features = false`; WASM consumers can use the dimension-specific imports,
including `/irregular`, `/irregular/web` and `/irregular/nodejs`. The minimum Rust
version remains 1.99. No PackingSolver or C++ runtime is required.

New physical and objective request objects reject unknown fields. JavaScript
numeric inputs must be finite; weights, density fractions, axle/stack load limits
and seeds must be nonnegative safe integers. Nullable limits accept explicit
`null` where declared. Large area/volume summary numbers retain ordinary
JavaScript precision limits.

Search/work budgets are documented per API and do not imply wall-clock deadlines.
Partial results and failed bounded searches do not prove infeasibility. Curves
use conservative approximation envelopes and finite angle samples. Loading uses
upright compatible columns and a generic two-support axle model. Optimality fields
cover only the objective and bound explicitly reported.

## Packages and verification

The Rust workspace, native Node package and WASM package use `0.6.0`; binding
implementation crates remain `publish = false`. Pushing `main` runs CI. Pushing
the `v0.6.0` tag runs CI, whose gated `publish` job publishes the packages
and creates the GitHub release.

The [testing guide](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/testing-confidence.md) lists the quality, isolated-feature
and native/WASM consumer checks. The [October 28 coverage report](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/experiments/2026-10-28-branch-90.md)
records 630 passing Rust tests, 43 Python tests, 96.88% production line coverage
and 90.53% branch coverage. These are recorded measurements, not a new coverage
run for the version bump.

The [expansion completion report](https://github.com/doublesharp/bin-packing/blob/v0.6.0/docs/experiments/2026-10-28-packingsolver-completion.md)
records native/WASM package, TypeScript and Chromium qualification and reference
comparisons. It retains quality losses, bounded-model limits and timing caveats;
it does not establish universal superiority or qualification on every platform.
