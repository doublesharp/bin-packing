# v0.5.0

Add bounded packing searches and retain the measured improvements from the seven solver experiments.

- Add Rust opt-in entrypoints `two_d::solve_2d_recombined`, `two_d::solve_2d_demand_aware`, `two_d::solve_2d_mixed_rotations`, `three_d::solve_3d_repaired` and `one_d::solve_1d_arc_flow`.
- Add `two_d::reuse` forecast evaluation and layout selection using physically recoverable offcuts, source-index maps and explicit material ceilings.
- Strengthen conservative geometric lower bounds in the existing supported 3D exact backend.
- Prune equivalent sequential saw states. Batched jobs bypass the canonical cache because its measured overhead outweighed the search savings.
- Add saw pruning diagnostics to Rust results and native/WASM TypeScript declarations. Existing binding entrypoints remain available; the new optimization entrypoints are Rust-only.
- Expand independent geometry, inventory, cost, budget, serialization and compatibility regressions. Check that Rust/npm versions, local lock entries and release notes stay synchronized.

## Compatibility

This pre-1.0 minor version adds public Rust types and functions. Rust callers constructing `SawSearchReport2D` literals must initialize `dominated_states`, `peak_dominance_units` and `dominance_table_saturated`. Older serialized reports deserialize with zero/false defaults for those fields. The saw output schema remains version 1.

The new searches have documented input/work limits and retain ordinary incumbents within their supported scope. Demand-aware and mixed-rotation examples improve restricted heuristics; full Auto already matches their sheet counts. Forecast results depend on the supplied forecast. Restricted pattern pools, bounded repairs and truncated integer searches do not establish unrestricted optimality.

## Packages

The Rust workspace, native Node package and WASM package use `0.5.0`. Binding implementation crates remain `publish = false`. Version preparation and a branch push do not publish packages or create a release tag.

See the [measured findings](../experiments/2026-10-14-packing-findings.md), [raw measurements](../experiments/data/2026-10-14-packing-measurements.json) and [source review](../experiments/2026-10-14-packing-review.md). Those measurements describe the recorded algorithm commits; the version bump does not rerun or broaden that performance evidence.

The required quality gate passes with 413 Rust tests and seven Python checks, plus two separately run doctests. All eight Rust feature combinations, nine WASM combinations and fuzz-target compilation/clippy checks pass. Cargo packages and verifies `bin-packing` 0.5.0.

Rebuilt native/WASM consumers pass 43 tests, 13 declaration checks, 300 solver-finder cases with 1,800 calls, and four Chromium package variants. Packed package checks verify compiled versions against manifests. These checks cover the available macOS arm64 host; other native platforms use the configured CI runners.
